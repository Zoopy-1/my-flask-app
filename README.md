# A股日频行情数据获取与存储系统 (Branch2)

本项目是一个用于获取、存储和管理全A股日频行情数据的数据管道工具。它使用 `akshare` 作为数据源，并将数据持久化到 SQLite 数据库中。

## 核心功能

- **自动化数据获取**: 从 `akshare` 接口获取所有A股的日线行情数据。
- **持久化存储**: 使用 SQLAlchemy ORM 将数据存储在本地 SQLite 数据库中，便于后续分析。
- **增量更新**: 系统能够自动检测数据库中的最新数据日期，并只获取此后产生的增量数据，极大地提高了日常更新的效率。
- **容错与恢复**: 支持全量恢复模式。如果数据库文件丢失或损坏，可以一键重新获取近一年的全部历史数据。
- **数据校验**: 提供独立的校验脚本，用于检查数据的完整性和准确性，确保数据质量。
- **模块化设计**: 项目代码被拆分为四个独立的文件，各司其职，结构清晰：
    - `database.py`: 数据库设置与模型定义。
    - `data_fetcher.py`: 数据源接口封装。
    - `main_updater.py`: 核心更新与恢复逻辑。
    - `validator.py`: 数据质量校验工具。

## 使用指南

请按照以下步骤操作来管理你的股票数据库。

### 第1步：初始化数据库

在首次运行前，你需要先创建数据库文件和数据表。

```bash
python database.py
```
这会在项目根目录下创建一个名为 `stock_daily_data.db` 的数据库文件。此操作只需执行一次。

### 第2步：首次数据加载 (全量恢复模式)

第一次使用时，你需要获取近一年的完整历史数据。

```bash
python main_updater.py --full-restore
```
这个过程会花费较长时间，因为它需要遍历数千支股票并获取它们一年的历史数据。请耐心等待。

### 第3步：日常增量更新

在首次加载完成后，你每天只需要运行以下命令来获取当天的新数据。

```bash
python main_updater.py
```
系统会自动从上次更新的日期开始获取，速度非常快。建议在每个交易日收盘后（例如下午4点后）运行此命令。

### 第4步：数据校验

你可以随时运行校验脚本来检查数据库中数据的健康状况。

```bash
python validator.py
```
脚本会报告最近交易日的数据量是否正常，以及是否存在“最高价低于最低价”等异常数据。
